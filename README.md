# Robot Management Platform

## Overview

A software platform for managing and monitoring robots.

This project aims to build a foundation for managing multiple robots
through software.

## Goals

- Manage robot information and status
- Monitor robot operation
- Collect and store robot data
- Manage communication between robots and the platform
- Improve system security
- Support multiple robots in the future

## Development Environment

- Windows
- WSL2
- Ubuntu
- Visual Studio Code
- Git / GitHub

## Development Policy

This project is developed independently of the robot control project.

The platform will initially use simulated robot data so that software
development can proceed without requiring a physical robot.
